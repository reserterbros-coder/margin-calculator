# margin-calculator
# Калькулятор прибыли и маржи

Простой калькулятор для продавцов на маркетплейсах: показывает, сколько вы зарабатываете с одной штуки товара после всех расходов, и при какой цене вы начинаете работать в минус.

Это один HTML-файл без зависимостей, сборки и серверной части. Его можно открыть двойным щелчком в любом современном браузере.

## Возможности

- Расчёт прибыли, маржи и ROI на одну штуку
- Цена безубыточности и цена для желаемой маржи
- Прибыль и выручка в месяц при заданном объёме продаж
- Наглядная шкала: на что уходит каждая часть цены
- Подсказка простым языком: теряете вы деньги или нет и что менять
- Выбор валюты (₽, $, €, kr, ₸, ₴)
- Светлая и тёмная тема (подстраивается под систему)
- Адаптивная вёрстка для телефона
- Введённые значения сохраняются в браузере (`localStorage`), кнопка «Сбросить» возвращает пример

## Быстрый старт

1. Скачайте файл `margin-calculator.html`.
2. Откройте его в браузере.

Для установки ничего не нужно. Без интернета тоже работает: не загрузится только шрифт Onest, будет использован системный.

## Что вводить

| Поле | Что это |
|---|---|
| Цена продажи | Цена, по которой покупатель реально покупает товар |
| Себестоимость | Закупка или производство одной штуки |
| Упаковка и прочее | Коробка, пакет, этикетка и мелкие расходы на штуку |
| Логистика и хранение | Доставка, хранение, обработка заказа, в деньгах на штуку |
| Комиссия площадки, % | Берётся из личного кабинета маркетплейса |
| Реклама, % от цены | Лучше брать из своей статистики |
| Возвраты и брак, % от цены | Лучше брать из своей статистики |
| Налог, % от выручки | Зависит от вашей системы налогообложения |
| Продаж в месяц | Планируемый или фактический объём |
| Желаемая маржа, % | Какую долю цены вы хотите оставлять себе |

Значения по умолчанию (цена 1500, себестоимость 400 и т. д.) приведены только как пример. Это не рыночные данные и не рекомендации.

## Как считается

Обозначения:

- `fixed` = себестоимость + упаковка + логистика (расходы в деньгах)
- `p` = комиссия + реклама + возвраты + налог (расходы в процентах от цены)
- `t` = желаемая маржа

Формулы:

```
прибыль            = цена − fixed − цена × p
маржа              = прибыль / цена
ROI                = прибыль / (себестоимость + упаковка)
цена безубыточн.   = fixed / (1 − p)
цена для маржи t   = fixed / (1 − p − t)
прибыль в месяц    = прибыль × продаж в месяц
выручка в месяц    = цена × продаж в месяц
```

### Пример

Цена 1500, `fixed` = 400 + 30 + 120 = 550, `p` = 20 + 10 + 5 + 6 = 41 %.

- Прибыль: 1500 − 550 − 615 = **335**
- Маржа: 335 / 1500 ≈ **22,3 %**
- ROI: 335 / 430 ≈ **78 %**
- Цена безубыточности: 550 / 0,59 ≈ **932**
- Цена для маржи 25 %: 550 / 0,34 ≈ **1618**

## Структура кода

Весь проект находится в одном файле:

- `<style>`: оформление, цвета заданы переменными CSS, тёмная тема переопределяет их
- `<body>`: форма ввода слева и блок результатов справа
- `<script>`: объект `D` со значениями по умолчанию, функция `calc()` с расчётом и отрисовкой, обработчики ввода и сохранения

Что можно поменять:

- Стартовые значения: строка `var D={...}` в начале скрипта
- Список валют: теги `<option>` в `select#cur`
- Формулы: функция `calc()`
- Цвета: переменные в `:root`

## Ограничения

- Модель упрощённая. Она не учитывает штрафы, платное хранение сверх нормы, курсовую разницу, кредиты и разовые расходы.
- Налог считается как процент от цены продажи. Точный расчёт зависит от режима налогообложения и лучше уточнить его у бухгалтера.
- Результат точен настолько, насколько точны введённые данные.
- Калькулятор ничего не загружает с маркетплейсов: все данные вводятся вручную.

## Приватность

Страница не отправляет данные на сервер. Введённые значения хранятся только в `localStorage` вашего браузера. Единственный внешний запрос это загрузка шрифта с Google Fonts.
